# Примеры

Каждый файл — самостоятельный скрипт, запускается из корня репозитория:

```console
$ python3 examples/01_first_test.py
```

| Файл | О чём |
|---|---|
| `01_first_test.py` | минимум: подать вход, прокрутить сканы, проверить выход |
| `02_timers.py` | виртуальное время, таймеры, чтение вложенного FB по пути |
| `03_reading_state.py` | `get` / `state`, TIME в наносекундах, перечисления |
| `04_unittest.py` | тот же стенд внутри `unittest`; почему падение не исключение |
| `05_a_project.py` | проект из нескольких файлов: DUT, библиотека, свой `TON` |
| `06_test_a_project.py` | готовый набор тестов на этот проект — образец для копирования |
| `07_functions.py` | прямой вызов `FUNCTION` и ручной прогон экземпляра FB |
| `08_mistakes.py` | как выглядят ошибки в тестах: опечатки, типы, границы |

`valve.st` — маленький блок для примеров 01–04. `project/` — мини-проект
(один объект CODESYS на файл) для примеров 05–08.

Более крупные примеры на реальном коде — в `benchmarks/`.
